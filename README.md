## Overview

Hack for Rust is an unofficial fan-made interface concept inspired by Rust's harsh survival environment, abandoned structures, resource gathering, and multiplayer gameplay.

The project focuses on UI design, visual customization, and menu organization. It does not provide functional hacks or gameplay modifications.

## Features

- Rugged survival-themed interface
- Post-apocalyptic visual elements
- Customizable dark themes
- Industrial accent colors
- Organized navigation menu
- Modular interface layout
